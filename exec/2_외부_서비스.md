# 2. 외부 서비스 정보

프로젝트가 가입·연동해 쓰는 외부 서비스와, 같은 환경을 다시 만들 때 필요한 정보. 키·비밀번호 값은 적지 않는다(넣는 곳은 [1_빌드_배포_매뉴얼.md](1_빌드_배포_매뉴얼.md) §1-4).

## 한눈에

| 서비스 | 용도 | 계정 · 비용 | 넣는 설정 |
|---|---|---|---|
| AWS EC2 (SSAFY 제공) | 메인 서버 — 웹 · DB · 브로커 · CI/CD · k3s 서버 | SSAFY 발급(도메인 `j15a106.p.ssafy.io` 포함) | SSH 키(pem) |
| Google Cloud Platform | 견적 DES 워커 VM 3대 | 결제 계정이 연결된 GCP 프로젝트 | GCP 콘솔, 템플릿 메타데이터 `k3s-token` |
| Gmail SMTP | 가입 인증 코드 · 견적서 PDF 메일 발송 | Google 계정 + 2단계 인증 + 앱 비밀번호 | `MAIL_USERNAME` · `MAIL_PASSWORD` · `MAIL_FROM` |
| Let's Encrypt | HTTPS 인증서 | 무료, 계정 없음(certbot 등록 메일) | `/etc/letsencrypt/` |
| SSAFY GitLab | 소스 저장소 · MR · GitLab CI | SSAFY 계정 | CI/CD 변수 `SONAR_TOKEN` · `GITLAB_REVIEW_TOKEN` · `GMS_API_KEY` |
| SSAFY GMS | MR 정적 분석 코멘트 요약(LLM) | SSAFY 발급 키 | `GMS_API_KEY` (CI 전용, 서비스 기능 아님) |
| NVIDIA (Isaac Sim · 드라이버 · 컨테이너 툴킷 · 에셋) | 3D 주행 검증 러너 | 계정 불필요, **Isaac Sim EULA 동의** | 러너 이미지 빌드 |
| Docker Hub | 모든 컨테이너 베이스 이미지 | 계정 불필요(익명 pull 한도 주의) | 각 Dockerfile · compose |
| jsDelivr · Google Fonts | 웹 화면 글꼴(Pretendard · DM Mono) | 계정 불필요 | `4_Web/SantaFactoryFE/index.html` |
| Tailscale | GPU 서버 ↔ EC2 임시 사설망 | Tailscale 계정(무료 플랜) | 각 장비 `tailscale up` |

**쓰지 않는 것:** 소셜 로그인(OAuth) 없음 — 이메일 가입 · JWT 자체 인증. 지도 · 결제 · 문자 등 외부 API 호출 없음. 백엔드가 서비스 중 인터넷으로 부르는 곳은 Gmail SMTP 하나다.

## 서비스별 상세

### AWS EC2 (SSAFY 제공)

| 항목 | 값 |
|---|---|
| 주소 | `j15a106.p.ssafy.io` (공인 IP 는 SSAFY 가 배정, 도메인도 SSAFY 가 연결) |
| OS · 사양 | Ubuntu 24.04.4 LTS, 4 vCPU · 16 GB · 309 GB |
| 접속 | `ssh -i <SSAFY 발급 pem> ubuntu@j15a106.p.ssafy.io` |
| 보안그룹 | 전 포트 개방(SSAFY 설정) → **ufw 로 막는다**: 22 · 80 · 443 전체, 5671 · 6443 은 GCP NAT IP 만 |
| 주의 | ufw 는 `allow` 추가와 `status numbered` → `delete <번호>` 만. `reload`·`enable`·`disable` 금지(22 가 끊기면 초기화뿐) |

### Google Cloud Platform

| 항목 | 값 |
|---|---|
| 프로젝트 · 리전 | `santafactory` · `asia-northeast3`(서울), 존 a · b · c |
| 사용 제품 | Compute Engine(관리형 인스턴스 그룹 `des-workers`, 인스턴스 템플릿 `des-worker-tpl-v2`), Cloud NAT(고정 IP `34.47.111.62`), IAP(콘솔 SSH) |
| 머신 | `c4-highcpu-8` **Spot** × 3, SMT 끔(물리 4코어), 외부 IP 없음 |
| 방화벽 | 들어오는 것은 IAP SSH `35.235.240.0/20` 만. 나가는 것은 NAT 를 거쳐 EC2 5671(AMQPS) · 6443(k3s) · 443 `/v2/`(이미지 pull) |
| 시작 스크립트 | `3_FMS/infra/gcp/start.sh` — k3s 에이전트로 합류(`role=sim-worker` 라벨) |
| 비용 | Spot 요금(회수 가능). 쓰지 않을 때는 그룹 크기를 0 으로 |

자세한 콘솔 절차: `3_FMS/infra/gcp/README.md`.

### Gmail SMTP

| 항목 | 값 |
|---|---|
| 서버 | `smtp.gmail.com:587`, STARTTLS (`application.yml` 기본값) |
| 준비 | 보낼 Google 계정에 2단계 인증을 켜고 **앱 비밀번호**를 만든다 → `MAIL_PASSWORD` |

| 끄기 | `MAIL_ENABLED=false` 면 메일을 보내지 않고 내용을 백엔드 로그에 남긴다(로컬 개발용) |

### Let's Encrypt (certbot)

- EC2 호스트 Nginx 에 `certbot --nginx -d j15a106.p.ssafy.io` 로 발급. 인증서 `/etc/letsencrypt/live/j15a106.p.ssafy.io/`.
- 같은 인증서를 443(웹)과 5671(AMQPS stream)이 함께 쓴다. 갱신은 certbot 패키지의 자동 갱신 타이머.

### SSAFY GitLab · GitLab CI

| 항목 | 값 |
|---|---|
| 저장소 | SSAFY GitLab 프로젝트 `S15P21A106` — 브랜치 `develop`(통합) · `release`(배포) · `feature/S15P21A106-<이슈>` |

### SSAFY GMS (LLM 프록시)

- 주소 `https://gms.ssafy.io/gmsapi/api.openai.com/v1/responses`, 모델 `gpt-5-mini` (`.gitlab-ci.yml`).
- MR 의 SonarQube 결과를 요약해 코멘트로 다는 CI 보조 기능에만 쓴다. 서비스(견적 · 검증)는 LLM 을 쓰지 않는다.

### Tailscale (임시)

- GPU 서버(팀 PC)와 EC2 를 사설망으로 잇는다 — 러너가 EMQX 1883 · MinIO 9002 에 붙는 경로.
- **임시 경로다.** GPU 서버를 클라우드(예: 임대 GPU)로 옮기면 공인 주소 + TLS + 출발지 제한 + 전용 계정으로 바꾼다.
