## 0. 이 문서의 지위

**[2026-08-31_B1e_벤치마크_결과.md](2026-08-31_B1e_벤치마크_결과.md)의 처리량 곡선을 대체하는 새 기준선.**
B-1e는 회전 0초·로봇 크기 0 가정이었고, Isaac 회전 충돌 이후 PIBT에 2칸 차체·회전 2틱·후진·스윙
예약이 들어왔다. B-5(θ 적용 스윕)의 비교 대상은 이 문서의 헤딩 모델 곡선이다.
B-1e 문서와 원자료는 이력·A* 비교용으로 보존한다.

조건은 B-1e와 동일: 확정 맵 wallA, **통로차단 ON**, 40주문(+입고 40), main 흐름,
로봇 {2,3,4,6,8,10,12,16} × 시드 {42,7}, uniform cost(θ 미적용). 두 계열:
`cell`(sim_v2 기본 = B-1e pibt_main과 동일) vs `heading`(`--heading`).
헤딩 상수: `TURN_TICKS=2`, `REVERSE_FACTOR=3.0`, `REAR_CELLS=1` (앞축 위치·각속도 실측 전 가정값).
**⚠️ 2026-09-03 Isaac 실측으로 코드는 `TURN_TICKS=1`로 바뀌었다.** 이 문서의 수치는 2틱 기준이라
현재 코드로 재실행하면 헤딩 계열 값이 달라진다. 맵 동기화(S15P21A106-135) 후 재실측해 새 문서로 대체 예정.
전 32회 실행 완주, 헤딩 계열은 `SIM_CHECK`와 동일한 점유 겹침 규칙으로 계획됨(스모크·데모에서 전수검사 통과).

## 2. 해석

- **로봇이 병목인 구간(2~8대)에서 회전 비용이 처리량 −5~−11%로 나타난다.** 이것이 지금까지
  회전 0초로 계산해 과장돼 있던 만큼이다. 리드타임은 +13~40% 늘어난다.
- **10대 이상은 차이가 없다** — 주문 40건이 소진되는 수요 제약 구간(핸드오프 함정 4). 엔진
  차이가 아니라 워크로드 한계. 헤딩 모델이 소폭 앞서는 것(+1~2%)은 시드 노이즈 수준.
- **무릎이 8대 → 10대로 이동.** 칸 모델은 8대에서 포화(163.4 ≈ 10대 163.8)했지만 헤딩 모델은
  8대 155.6 → 10대 165.7로 10대에서 포화한다. 같은 워크로드에 대해 **회전을 반영하면
  권장 대수가 한 단계 올라간다** — 견적 제품의 핵심 출력이 바뀌는 크기라, 회전 시간 상수
  (`TURN_TICKS`)의 실측 확정이 중요하다.
- 태스크당 회전 횟수는 헤딩 모델이 오히려 적다(5.7~11.3 vs 8.8~15.4): 회전에 비용이 붙으니
  거리장이 회전을 피하는 경로를 고른다. 대신 회전 1회가 2틱이라 총 소모 시간은 늘어난다.
- 후진은 로봇당 실행당 80~110칸 수준(1~2%의 이동)이며 대수에 따라 증가 — 밀집에서 3점 회전과
  밀어내기 후퇴가 늘기 때문. `REVERSE_FACTOR` 3.0에서의 값이고, Isaac 실행 규약에 후진이
  들어가지 않으면 이 부분은 다른 대안(대기)으로 흡수돼 처리량이 더 내려갈 것.
- 재계획 사용 틱이 대수와 함께 늘어(16대에서 ~2900틱) 밀집 정체가 잦음을 보여준다. 정체
  해소는 되지만 이 구간의 KPI에는 라이브니스 장치의 우회 비용이 섞여 있다.

## 3. 유의사항

- 헤딩 상수 3개는 가정값. Isaac 파트의 앞축 위치·각속도 실측 후 재실행이 필요하며, 그때
  이 문서를 갱신한다 (스크립트·조건 동일).
- 통로차단 ON 조건이라 랙 사이 세로 통로는 사용되지 않는다. θ 교대 순환은 세로 통로 규칙이므로
  B-5 스윕은 통로차단 OFF도 함께 측정해야 한다 (B-2 데모는 OFF에서 수행).
- 수요 제약 때문에 10대 이상의 차이는 이 워크로드로는 판별 불가. 무릎 이동을 더 정밀하게
  보려면 주문 도착률(`ORDER_MEAN_GAP`)을 올린 고부하 시나리오가 필요 — 서빙 트랙의
  Peak 시나리오와 함께 설계.
- 실행 시간: 헤딩 계열 실행당 2~17 s (칸 모델 0.3 s). 재계획 다익스트라가 주 비용.
