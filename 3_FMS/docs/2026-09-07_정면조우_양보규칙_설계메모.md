# 정면 조우 양보 규칙 — 설계 메모 (2026-09-07, 라이브니스 이슈 ③ 후보)

배경: [B-5 결과 §5](2026-09-07_B5_θ적용_FleetSweep_결과.md)(22대·시드 101 정면 교착, 중립 STALL 3건 / θ 0건),
shift12 리플레이 t=739~769 로봇 0 vs 3 "밀고 밀리기" 진동(6틱 주기 = `REPLAN_HOLD`), B-5 중립 후진 비율 5.4~6.7 %(θ 2.6~3.9 %).
근거 코드: [pibt_core.py](../sim_engine/pibt_core.py) `candidates_h`·`Replanner`·`REPLAN_HOLD`, [fms_kernel.py](../sim_engine/fms_kernel.py) `_tick_heading` 우선순위.

## 1. 현상

폭 1 통로에서 두 로봇이 반대 방향 목표로 마주치면, 높은 우선순위가 낮은 쪽을 **후진으로 밀어낸다**(회전 불가·대기 불가라 후진이 유일한 합법 후보).
밀리는 쪽의 정체 카운터가 `REPLAN_AFTER`(8)를 넘으면 상대를 장애물로 재계획 → 재계획 지도가 "뒤로 돌아가라"고 하여 이번엔 밀던 쪽이 물러남 →
`REPLAN_HOLD`(6) 만료 → 다시 원래 지도로 밀어붙임. 결과: 3틱 밀고 3틱 밀리는 진동. 대개 20~30틱에 풀리지만 (a) 후진 낭비, (b) 배수 구간에서 영구 교착(STALL)으로 굳기도 한다.

## 2. 사용자 제안 (2026-09-07)

**우선순위 낮은 로봇이 비킬 때, 높은 로봇의 진행 방향과 다른 쪽으로 비킨다.** 즉 상대 경로 위에서 한 칸씩 뒤로 밀리는 대신 **상대 경로 밖으로 나간다.**

## 3. 구체화 — 붙여야 할 것 둘

지금도 밀리는 로봇은 겹치지 않는 후보 중 최선을 고르므로, 옆 칸이 있으면 이미 옆으로 비킨다. 부족한 것은:

| | 문제 | 규칙 |
|---|---|---|
| ① 대피 칸 | 폭 1 통로에는 "옆"이 없다. 비킬 곳은 뒤쪽 교차점의 가지나 밴드 | **대피 칸 = 뒤로 물러나며 처음 만나는, 상대 경로 위에 없는 칸.** 상대 경로 = 상대 거리장을 따라 전방 N칸(N = 두 로봇 간격 + 여유 3) |
| ② 커밋 | 매 틱 다시 판단해 6틱마다 뒤집힘 | **비키기로 했으면 상대가 지나갈 때까지 유지.** 양보자: 임시 목표 = 대피 칸(stay_map 류), 재계획·대기 상승 OFF. 통과자: 재계획 OFF(물러나지 않음). 해제 조건: 통과자 차체가 양보자 체비쇼프 반경 2 밖 **또는** 통과자 경로가 양보자 칸을 더 이상 포함하지 않음 |

### 감지 조건 (정면 조우)

A(높음)의 최선 후보 칸에 B(낮음)가 있고, B의 목표 방향(거리장 감소 방향)이 A의 진행 방향과 반대이고, B가 제자리 회전 불가(`turn_ok` 양쪽 False).
회전 가능하면 기존 밀어내기(옆으로 회전해 비킴)가 이미 동작하므로 규칙 대상 아님.

### 누가 비키나 — 실험으로 정함

- **안 A (제안 그대로)**: 우선순위 낮은 쪽. 단순, 우선순위 의미 보존.
- **안 B**: 대피 거리(대피 칸까지 칸 수)가 짧은 쪽, 동률이면 낮은 쪽. 낮은 쪽 대피 칸이 10칸 뒤·높은 쪽은 1칸 뒤인 경우 전체 손실이 작다.
- 둘 다 구현해 고부하 격자 + STALL 재현 3건으로 A/B.

### 연쇄

B 뒤에 C가 붙어 있으면 B가 물러날 수 없다. PIBT 밀어내기 연쇄가 C를 밀지만 커밋은 전파되지 않는다. **1차 구현은 연쇄 1단(B만 커밋)**, C는 기존 장치에 맡기고 STALL 재현으로 부족한지 본다.

## 4. 기존 장치와의 관계

- 장치 ⑤(도킹 칸 이탈 최우선)·그 뒤 칸 확장(계획 ③-a)과 **별개**. 뒤 칸 교착은 "스테이션 위에 서 있는 쪽이 비킨다"는 정적 규칙, 이건 통로 정면 조우의 동적 규칙.
- 정체 재계획(`Replanner`)은 그대로 두되, 양보 커밋 중인 두 로봇에게는 적용하지 않는다. `REPLAN_HOLD` 6은 이 규칙이 들어가면 재검토 대상(진동 원인이 사라지면 더 짧아도 됨).
- θ의 `loop_dir`(순환 일방통행)·`wait_cost`는 정면 조우 **발생 자체**를 줄인다(B-5: 후진 절반). 이 규칙은 발생 후 **해소**를 빠르게 한다. 둘은 보완.
