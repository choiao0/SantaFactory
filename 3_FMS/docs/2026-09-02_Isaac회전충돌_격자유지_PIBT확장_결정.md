### 4-2. 실행 계층 요구사항 (Isaac/ROS 파트 전달용 — 코드는 그쪽 소관)

1. 회전은 **셀 중심에서 정지 → 제자리 회전 → 직진** (스팟턴). 기준점 = **앞축을 셀 중심에 정렬.**
2. 경유점 도달 판정 오차 ≤ 0.1m (현 patrol.py `WP_TOL=0.45`는 코너를 깎음).
3. **틱 배리어 동기**: 전 로봇이 이동·회전 완료 후 다음 틱 발행. 없으면 가감속 편차로 재발.
3b. **후진 1칸 프리미티브** (v<0, 헤딩 유지): 벽에 붙은 레인(충전기 열)에서 회전만으로는
    빠져나올 수 없어 계획 계층이 후진을 쓴다 — 헤딩 설계 문서 §3 참고.
4. 확인 요청: iw.hub 앞축의 정확한 종방향 위치(앞끝에서 m), 회전 각속도(스윙 칸·회전 틱 산정용).

## 5. 왜 가중 다익스트라인가 (①의 근거)

PIBT 후보 점수 = `edge_cost + dist[다음 칸]`. dist가 비가중이면
전진 = `gain + (d−1)`, 대기 = `wait + d` → `gain ≥ wait + 1`이면 대기가 매 틱 이겨 **영구 정체**
(B-2에서 gain 3.5/wait 1.0으로 실측 STALL). θ 범위(gain≤3.5, wait≥0.5)에 안전한 값이 없다.
가중이면 최적 경로 위 전진 = `edge + (d − edge) = d` < 대기 `wait + d` → **어떤 θ든 전진이 이김.**
동시에 비싼 통로는 dist 자체가 커져 진입 시점부터 우회가 유도됨 → B-2의 "진입 엣지 확장" 꼼수 제거.
목표에서 역방향 다익스트라 1회로 전 칸 dist 확보 → 기존 목표별 캐시 구조 유지. θ 변경 시 캐시 무효화 필요.
