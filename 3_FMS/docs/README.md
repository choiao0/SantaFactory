# 3_FMS/docs

현재 유효한 FMS 설계와 실측을 주제별 문서 8개로 정리한다. 날짜 기록은 원문 근거로 로컬에
보관하지만 git 추적 대상이 아니며, 새 링크는 아래 문서의 구체적인 절을 가리킨다.

## 주제 문서

### [이동계층 PIBT](이동계층_PIBT.md)

Isaac 회전 충돌과 셀 확대 기각부터 `(칸,방향)` 상태, 2칸 점유, 회전 스윙 예약을 설명한다.
가중 다익스트라·성능 최적화, 다중 칸 충돌과 우선순위, 라이브니스 장치 5종을 모았다.
STALL 재현 3건과 아직 구현 전인 정면 조우 양보 후보, 관련 검증 명령도 이 문서에 있다.

### [시스템 구성도](시스템_구성도.md)

컨테이너·큐·브로커 한 장 그림(mermaid). 프론트 → 백엔드 → RabbitMQ → 견적 워커 ×2 → 결과, 최적 1건 → host-orch → EMQX → Isaac·fms-core → 검증 결과.
견적·물리 검증 두 시퀀스, 브로커 두 개(RabbitMQ 일감 분배 / EMQX 실시간 상태·명령)의 역할, 이미지 6개에 든 것을 모았다.

### [커널·시뮬 구조](커널_시뮬_구조.md)

현재 `sim_engine` 패키지 구조와 틱 루프, 로봇 상태머신, 태스크 흐름·배차 규칙을 설명한다.
`FmsKernel` 인터페이스, SimPy의 고정 시간·교대·배터리 도크, Isaac 내보내기를 모았다.
Lifelong MAPF 해석, ROS/Isaac 연결 순서와 계약 기준값 3개를 확인할 수 있다.

### [맵·충전 존](맵_충전존.md)

계획 격자 1.0 m 결정과 FMS·Isaac 맵 불일치, 보수적 정답지 생성·동기화 절차를 설명한다.
동쪽 충전 존의 좌표·용량·대안·위험, 초기 배치와 최근접 복귀·재선택 규칙을 모았다.
존 지표 5종, 2번째 존 폐기 근거와 맵·존 검증 명령을 확인할 수 있다.

### [θ 경로와 기준선](θ_경로_기준선.md)

θ 11개 스키마와 비용 규약, `from_theta`의 배타 조립·가중 거리장 연결을 설명한다.
감도 결론과 시드 역할, B0→B0′→B0″ 계보, 고부하·대수별 θ·B-5 수치를 모았다.
3~4대 절감, wallA 대수 축 θ 한 벌 판정과 견적 엔진 입력·results 파일 지도가 있다.

### [견적 워커](견적_워커.md)

백엔드 큐 명세 v0.3을 우리 커널에 붙이는 방법: 요청 필드 → 시뮬 인자, SUMMARY → KPI 14키, 실패 처리, 배포 자리.
백엔드와 맞출 항목(대수 상한 8, 시드 42, 가동률 정의)을 모았다. 이슈 S15P21A106-155.
-158 주문 자체 생성(2026-09-14 제거 — 백엔드 생성기로 이관, -197), -182 워커 병렬(기본 2, 로컬 5개 실측 3.3배) + 백엔드 배치 발행·조기 종료 제안.

### [주문 생성기](주문_생성기.md) — 2026-09-14 운영 제외, 알고리즘 근거 문서로만

신발 창고 공개 데이터(Mendeley pf2w725pw3)에서 라인 수·수량·SKU 편중·웨이브 시각 분포를 추출해 우리 매장·상품·랙 위에
하루치 `outbound[]`(명세 §1-1 형식)를 만든다. 릴리스 기본 웨이브, ABC 는 인기 가중치만, 입고 보류. 이슈 S15P21A106-153.
시뮬 연결(-156): `--orders-file`·`--capacity`, 랙 → 버퍼 매핑 `map/rack_buffers.json`, `slice_orders.py` 시간창 자르기, 첫 비교 표는 커널·시뮬 구조 문서에.

### [합성 창고 생성기](합성_창고_생성기.md)

파라미터 8개로 창고를 만들고 **토폴로지를 같이 낸다** — 추출기를 일반화하지 않고 로드맵 3단계로 간다.
wallA 를 그 파라미터로 재현해 링 영역 1 m 통행성·토폴로지 차이 0 을 확인했고, 규칙에서 안 나오는
실측 구조물 121칸을 사각형 15개로 적어 뒀다. 데이터셋 기본 모드는 랙 기하 3축만 흔든다 — 격자 112개를 다 만들어 두고(2.3 s) 라벨링을 25개부터 시작한다.
공식 맵 회귀(기준값 3개·80행·거리장)와 바뀐 코드 목록도 이 문서에. 이슈 S15P21A106-139.

| 모델·조건 (`base 6 40 42 1` 뒤 인자) | makespan | tasks/h | 비고 |

| 칸 + 고정 홈 (`--cell --fixed-homes`) | 2970 | 127.3 | 칸 모델 — 불변 |

| **기본 헤딩 + 존 + 차선 gain 2 + 양보 + 회전 마스크** | **10647** | **142.0** | v3.6 (v3.5 는 2785 / 135.7) |

> `--footprint=legacy`(회전 마스크 끔)는 10442 / 144.8 · 9805 / 154.2.
