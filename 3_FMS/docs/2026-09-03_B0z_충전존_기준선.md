## 0. 이 문서의 지위

**B0′를 대체하는 기준선.** B-5(θ 적용 스윕)의 비교 대상은 이 문서의 헤딩 계열이다.
단, **맵은 아직 8/31 복사본**이다(맵 파트 벽있음 세트 미수신). 맵 동기화 후 같은 스크립트로 한 번 더 돌려
이 문서를 갱신한다 — 그때까지는 "구성 변화(존·회전 1틱)의 효과"를 읽는 용도.

조건은 B-1e/B0′와 동일: wallA 복사본, **통로차단 ON**, 40주문(+입고 40), main 흐름,
로봇 {2,3,4,6,8,10,12,16} × 시드 {42,7}, uniform cost(θ 미적용). 두 계열:
`cell`(칸 모델) vs `heading`(`--heading`). **둘 다 충전 존 기본**(초기 배치·복귀 = 존 c103~108×r48~66, 106칸).
헤딩 상수: `TURN_TICKS=1`(Isaac 실측), `REVERSE_FACTOR=3.0`, `REAR_CELLS=1`. 전 32회 완주.

### 읽는 법

1. **존 자체는 처리량에 중립.** 칸 모델에서 존 vs 고정 홈 차이가 전 구간 ±3% 안(시드 노이즈 수준). 존 위치가
   기존 charger 열(c105)과 같은 동쪽 밴드라 복귀 거리가 사실상 같다. 16대 −3.0%는 수요 포화 구간(§2)이라
   해석하지 않는다.
2. **회전 2틱 → 1틱이 헤딩 모델 저·중부하를 끌어올렸다.** 2~6대에서 +2~8%, 6대에서 가장 크다(+8.2%, 리드타임
   502→382 s). 헤딩/칸 격차가 B0′의 −5~−11%에서 **−1~−9%**로 줄었고 6대에서는 −0.8%로 거의 같다.
3. **무릎은 그대로: 칸 8대, 헤딩 10대.** 헤딩 8대 153 → 10대 164로 아직 오르고 10대부터 평탄. 칸은 8대에 이미 평탄.
4. 8대 이상은 두 모델·두 구성이 전부 160~167에 모인다 — 수요 제약(40주문)이지 엔진 차이가 아니다(함정 4).

## 2. 충전 존 지표 (구현 설계 §4)

| n | 존 안 복귀 대기 [틱] 칸 / 헤딩 | 재선택 [회] 칸 / 헤딩 | 비임무 밀림 이동 [칸] 칸 / 헤딩 | 예약 무시 |
|---|---|---|---|---|
| 2~6 | 0 / 0 | 0 / 0 | ≤10 / ≤20 | 0 |
| 8 | 0 / 3.5 | 0 / 0 | 20 / 21 | 0 |

- **존 안 정체는 헤딩 모델 10대부터 나타나 16대에서 급증**(144 틱 ≈ 실행의 6%·로봇당 9틱). 아직 처리량엔 안 보이지만
  (수요 포화 구간) 곡선 기울기가 가파르다 — 20대 이상 고부하 시나리오에서는 병목 후보. 결정 §4 ①의
  "통로 쪽부터 채움 + 서향 정차 선호" 규칙은 **아직 넣지 않는다**: 맵 동기화 후 재실측에서 같은 경향이면 그때.
- 재선택(목표 칸에 다른 로봇이 주차)은 16대에서 6회. 예약 규칙(체비쇼프<2 제외)이 대부분 막고 있다.
- 비임무 밀림 이동은 칸 모델이 더 많다(150 vs 97) — 점로봇은 쉽게 밀리고, 2칸 차체는 밀어내기가 잘 실패해서
  대신 대기·재계획으로 간다(함정 8). 두 모델 모두 `drive`·util에서 제외돼 있음을 확인.
- **동시 주차 최대 = n**(전 구간). 시작·종료 시 전원이 존 안이라 당연한 값 — 용량이 걸리기 전(`zone_degraded=0`)엔
  정보가 없다. 견적 지표로 쓰려면 "임무 중 존 안 체류 로봇 수 분포"로 바꿔야 함(후속).

헤딩 비용(태스크당 아님, 실행 합): 회전 668→1484틱, 후진 252→1498칸, 재계획 446→3588틱 (2→16대).
B0′ 대비 회전 틱은 1틱 전환으로 약 40% 감소(6대 1494→768), 재계획은 존 진입·주차 때문에 12대+에서 증가(2542→3441).

## 3. 실행 시간

칸 0.3~0.5 s, 헤딩 3~18 s / 실행(16대). 스윕 전체 약 4분. 성능 최적화(남은 작업)의 기준 CSV는 이 문서의 것.

## 4. 다음

2. 헤딩 모델 기본값 전환 여부 — 헤딩/칸 격차가 6대 이후 ±5% 안이라 전환 비용은 작다. 맵 동기화 재실측 후 결정.
