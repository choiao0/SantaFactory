## v1에서 바뀐 것 — 하한 2개

```
aisle_alt_boost:  0.4~1.0  →  0.5~1.0
station_in:       0.4~1.0  →  0.5~1.0
```

최종 비용 clamp 하한이 0.5(명세 §12)라 `[0.4, 0.5)`는 단독 적용 시 항상 0.5로 잘린다.
서로 다른 θ가 같은 비용을 내므로 BO는 축의 일부가 평지가 되고, AI는 서로 다른 라벨이
같은 결과를 내는 모순을 학습한다.

## 비용 조립 규칙

```
1. 모든 간선을 1.0에서 시작
2. 한 간선에 아래 그룹 중 "가장 먼저 걸리는 하나"만 적용
     station 접근 스퍼 → loop_mask → 교차로 진입 → 통로 내부
3. main_aisle_gain 은 위와 독립으로, 양 끝이 main_aisle 인 간선에 항상 곱
4. 마지막에 한 번만 [0.5, 5.0] 으로 clamp  (규칙별 clamp 금지 — 순서가 결과를 바꾼다)
```

배타 규칙이 없으면 `3.5 × 3.0 × 1.2 = 12.6`이 5.0으로 잘려 파라미터 식별이 불가능해진다.
적용하면 최악이 `3.5 × 1.2 = 4.2 < 5.0`이다.

`edge_cost[y, x, d]` = 셀 `(y,x)`에서 방향 `d`의 이웃으로 **나가는** 간선 비용.
방향은 명세 §3-2 북0/동1/남2/서3.

## 규약 주의 — `station_entry_dir`

명세 §6-3은 이 값을 "작업 자리에서 가장 가까운 **큰 통로 쪽** 방향"으로 정의한다.
즉 **station → 통로** 방향이므로 진입 이동은 그 반대다.

```
station_entry_dir = 1(동)
  → 진입 이동          = 3(서)   ← station_in 대상
  → 진입로 역주행 이탈 = 1(동)   ← station_out 대상
```

이름대로 이동 방향으로 읽으면 `station_in`과 `station_out`이 뒤바뀐다.

## 중립 θ

전 배율 1.0이 계약 범위 안에 표현 가능하다 (`GuidanceTheta.neutral()`).
이 θ로 만든 `Guidance`는 B0 기준선 KPI를 그대로 재현해야 한다 — `from_theta` 배관의
첫 회귀 테스트.

## 미합의 / 후속

| 항목 | 내용 |
|---|---|
| `station_in/out` 범위 | 스퍼 전체 vs 마지막 간선 1개. 후자면 사실상 무효인 파라미터가 된다 |
| `station_out` 예외 | `walkable` 이웃 ≤1인 station엔 미적용 (로봇이 작업자리에서 안 나옴) |
| `main_aisle_gain` 상한 | 최적값이 1.2에 붙어 나오면 1.6까지 확대 |
| 하한 포화 | `0.5 × 0.5 = 0.25`로 잘림. 실측 후 범위 조정 또는 clamp 하한 인하 |
