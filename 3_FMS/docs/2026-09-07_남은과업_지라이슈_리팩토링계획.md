3. **한 커밋 = 한 종류의 이동.** 파일 이동과 내용 수정을 같은 커밋에 섞지 않는다(리뷰·bisect 가능).

## 4. 문서 정리 계획 (⑦)

### 4-1. 현재

### 4-2. 원칙

- 대체된 문서는 파일 첫 줄에 `> **대체됨** → [새 문서](...)` 배너 한 줄.
- 그림·html은 `docs/img/`, `docs/schema/`로 옮기고 링크 갱신(md 3개).
