# 남은 과업 계획

이 문서는 2026-09-07의 남은 과업 기록에서 실행 순서, 지라 초안 13건, A트랙 요청과
진행 규칙을 옮기고 관련 입력을 부록에 모은 것이다. ⑤·⑥·⑦의 완료 상태만 현재 작업에
맞춰 표시했으며 새로운 과업이나 결론은 추가하지 않는다.

## 한 문장

실험 장치는 끝났고, **정확히 재기(B-5) → 정리하기(레거시·코드·문서) → 견적 엔진으로
포장하기** 순서다. 결과가 바뀌는 라이브니스·배차 변경은 B-5 수치를 보존한 뒤 진행한다.

## 실행 순서

```text
① 시드 합의(완료) ─► ② B-5 θ 스윕(완료) ─► ⑤ 레거시(완료) ─► ⑥ 코드분리(완료) ─► ⑦ 문서(완료)
                              │                                         │
                              └─► ③ 라이브니스 ─► ④ dmap_h ──────────────┘─► ⑧ 견적 설계 ─► ⑨ 견적 구현
                                                                            ├─ ⑩ 배터리 레버화
                                                                            ├─ ⑪ 토폴로지 일반화
                                                                            └─ ⑫ 워치독·⑬ VDA5050
```

- ③·④는 결과가 바뀌므로 계약 버전 업과 80행 재측정이 필요하다.
- A트랙 study가 실행되는 사이에는 ③·④를 머지하지 않는다.
- ⑤·⑥·⑦은 결과 불변 작업이며 기준값 3개·80행·내보내기 동일성을 유지한다.
