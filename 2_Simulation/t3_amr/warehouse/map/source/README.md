# T3 창고 맵 — DXF → occupancy grid (v6.0)

설계도 DXF(64m x 96m 철골 창고)를 0.1m/셀 occupancy grid로 변환하고, 물류 레이아웃
(랙·컨베이어·스테이션 46개소·파렛트 밴드)을 얹는다. 이 grid가 DES·SIL·씬 빌더가
공유하는 단일 소스다.

## 파일 (`map/`)

| 파일 | 역할 |
|---|---|
| `warehouse_layout_v5_5_final.py` | 맵 생성기 — DXF 파싱→래스터→레이아웃→자가검증 |
| `Factory_Building_Design.dxf` | 설계도 원본 (레이어 판독·치수 실측의 원천) |
| `occupancy_grid.npy` | 산출 grid (uint8) — 셀값 아래 표 |
| `obstacle_mask.npy` | 0.8m 팽창 장애물 (플래너·경로 검증 기준) |
| `rack_units.npy` / `columns.npy` / `stations.json` | 랙 세그먼트 / 실기둥 중심 12 / 스테이션 좌표(57개소) |
| `zones.json` | **구역 정의 A~V 22개** — 구역 = 통로 반쪽 + 양쪽 랙 행 3칸씩(6랙), 버퍼·랙 좌표 포함 |
| `map.pgm` + `map.yaml` | ROS 표준 맵 (Nav2 호환) |
| `grid_full.png` | 전체 레이아웃 미리보기 |

셀값: 0=빈공간 · 1=구조체 · 2=랙 · 3=스테이션 · 4=문 · 5=컨베이어·작업대 · 6=바닥 파렛트

## 실행

```bash
cd map && python warehouse_layout_v5_5_final.py     # ezdxf·numpy·scipy·matplotlib 필요
```

끝에 자가검증이 돈다 — **팽창 장애물 기준** 스테이션 도달성 46/46 실패 시 exit 1.
(원시 그리드 연결성 검사는 팽창역 안 도킹을 통과시키는 함정 — 반드시 팽창 기준)

## 판독·수정 이력 요점

- DXF 레이어: `_4`=축선, `_15`=축선 버블(기둥 검출 보조), `_3`=실구조(상부 구조선 제외)
- 기둥 최소화(v5.7): 십자 심볼 98→12개(릿지 지지열만), 4.4m 지우기 박스 + 외벽 스윕
- 외벽 봉합(v5.9): 스윕 코너 관통 가드(`~wall_band`) + 파일라스터 자리 단절 봉합 —
  문 구간(양 끝벽 6.3m x 2개소씩)의 셀값 4는 보존
- 문 구간은 "통행 가능한 개구"가 아니다: 값4 스트립 양옆에 전고 벽 라미나(값1)가
  남아 봉인 상태(실측 — 씬도 폐쇄 셔터로 표현). AMR 동선은 전부 실내라 운영 무관
- 구역제(v6.0): 랙 유닛 4.0→3.0m, 밴드 2분할(남 47.0~56.0 / 북 58.7~67.7 —
  중앙 기둥 셀 56.2~58.5 실측 회피). 구역 경계가 더블로우 가운데를 지나 한 구역 =
  통로 반쪽 + 마주보는 랙 행 3칸×2 = 6랙. 버퍼 22개(북 A~K y69.4 / 남 L~V y46.0 —
  팀 CSV의 46.2는 v5.7-A 랙 밴드 기준이라 0.2m 파생 편차). 스테이션 46→57,
  자가검증 57/57 도달. 참고 자료: grid_v56a_wall_full.png · station_coords_blue.csv
